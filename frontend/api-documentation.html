1. Introduction

The FinEdge Banking Application provides a comprehensive set of REST APIs for integrating with banking services. This documentation outlines all available endpoints, request/response formats, and provides integration examples.

The API uses JSON for data exchange and standard HTTP response codes to indicate success or failure.

Base URL

All API endpoints are relative to the base URL of your deployment:

https://your-deployment-url.replit.app

2. Authentication APIs

FinEdge uses session-based authentication. A session cookie is issued upon successful login which must be included in subsequent requests.

Endpoint Method Description Request Body Response
/api/register POST Create a new user account { username, password, firstName, lastName, email, phoneNumber } User object (without password)
/api/login POST Authenticate user { username, password } User object (without password)
/api/logout POST End user session None 200 OK
/api/user GET Get current user info None User object (without password)

Example: User Registration

POST /api/register

3. Account APIs

These endpoints allow for managing bank accounts. All endpoints require authentication.

Endpoint Method Description Request Body Response
/api/accounts GET Get all user accounts None Array of account objects
/api/accounts/:id GET Get specific account None Account object

/api/accounts/:id PATCH Update account Fields to update Updated account object

9. API Security

All API endpoints (except /api/login and /api/register) require authentication. The system uses session-based authentication with the following security measures:

  • Password hashing using scrypt with salt
  • CSRF protection
  • Session expiration (24 hours)
  • Secure, HTTP-only cookies in production
Note: Always use HTTPS in production environments to protect sensitive data in transit.

10. Integration Examples

Authentication and Account Retrieval

async function loginAndFetchAccounts(username, password) {
  // Login
  const loginResponse = await fetch('https://your-deployment-url.replit.app/api/login', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include', // Important for session cookies
    body: JSON.stringify({ username, password })
  });
  
  if (!loginResponse.ok) {
    throw new Error('Authentication failed');
  }
  
  const user = await loginResponse.json();
  console.log('Logged in as:', user.firstName, user.lastName);
  
  // Fetch accounts
  const accountsResponse = await fetch('https://your-deployment-url.replit.app/api/accounts', {
    credentials: 'include' // Important for session cookies
  });
  
  if (!accountsResponse.ok) {
    throw new Error('Failed to fetch accounts');
  }
  
  const accounts = await accountsResponse.json();
  return accounts;
}

Making a Transfer Between Accounts

async function transferBetweenAccounts(fromAccountId, toAccountId, amount, description) {
  const response = await fetch('https://your-deployment-url.replit.app/api/transactions', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include',
    body: JSON.stringify({
      accountId: fromAccountId,
      recipientAccountId: toAccountId,
      amount: amount.toString(),
      description: description || 'Account transfer',
      transactionType: 'transfer',
      category: 'Transfer'
    })
  });
  
  if (!response.ok) {
    const errorData = await response.json();
    throw new Error(errorData.error || 'Transfer failed');
  }
  
  return await response.json();
}

Creating and Paying a Bill

async function createAndPayBill(payee, amount, dueDate, accountId) {
  // 1. Create the bill
  const createResponse = await fetch('https://your-deployment-url.replit.app/api/bills', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include',
    body: JSON.stringify({
      payee,
      amount: amount.toString(),
      dueDate: new Date(dueDate).toISOString(),
      status: 'pending'
    })
  });
  
  if (!createResponse.ok) {
    throw new Error('Failed to create bill');
  }
  
  const bill = await createResponse.json();
  
  // 2. Pay the bill
  const payResponse = await fetch(`https://your-deployment-url.replit.app/api/bills/${bill.id}/pay`, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include',
    body: JSON.stringify({ accountId })
  });
  
  if (!payResponse.ok) {
    throw new Error('Failed to pay bill');
  }
  
  return await payResponse.json();
}
